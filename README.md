# LiteWall

Ultra-lightweight live wallpaper engine for low-end Windows 10/11 PCs built with C# (.NET 8), WPF, and Edge WebView2.

## Features
- Near-zero resource usage with automatic fullscreen pause
- Interactive desktop wallpapers (includes Pomodoro Focus Timer)
- Built-in AI Prompt Generator for non-coders
- Drag-and-drop support for .html, .mp4, .webm, .gif, .png, and .jpg

## Quick Start
```bash
dotnet run --project src/LiteWall
```
